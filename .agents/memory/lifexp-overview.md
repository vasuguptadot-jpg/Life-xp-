## Stack
- **Monorepo**: pnpm workspaces
- **API**: Express + Drizzle + PostgreSQL (Replit-managed DB)
- **Web**: React 19 + Vite 7 + Tailwind 4 + Wouter + React Query + Orval codegen
- **Mobile**: Expo (task cancelled for now)
- **Auth**: JWT access + refresh tokens (SESSION_SECRET secret)

## Design System (current)
Pure black (#050505) liquid glass glassmorphism — NO accent colours.
- Cards: `glass` / `glass-md` / `glass-heavy` utilities (rgba white 4–9% + backdrop-blur)
- Borders: `rgba(255,255,255,0.07–0.14)`
- Primary: white; destructive: red (safety only)
- Shadows: deep dark (`rgba(0,0,0,0.7–0.9)`)
- Radius: 18px (--radius: 1.125rem)
- Attribute display: monochrome with CSS var `--attr-opacity` differentiation

## API routes (all under /api)
- Auth: signup, signin, refresh, logout, /auth/me
- Users: GET/PATCH/DELETE /users/me (returns createdAt, lastLoginAt)
- Onboarding: GET /onboarding, PATCH /onboarding/step, /profile, /goals, POST /archetype, /complete
- Progression: GET /progression/summary, GET /progression/attribute-history ← NEW
- Quests: GET /quests, /quests/catalogue, /quests/recommended, POST /quests/assign/:id,
          GET/PATCH /quests/:id, POST /quests/:id/complete, POST /quests/:id/abandon ← NEW

## Key types (generated by orval from openapi.yaml)
- QuestTemplate: now includes instructions, difficulty, targetUnit, verificationRequirement, xpReward, primaryAttributes
- XpTransaction: now includes description, sourceId
- AttributeHistoryEntry: id, userId, attribute, delta, sourceType, sourceId, createdAt

## Features surfaced in web UI
1. Quest detail dialog — instructions, difficulty, targetUnit, verificationRequirement, XP reward breakdown
2. Abandon quest (with inline confirmation)
3. Attribute history table on dashboard
4. XP feed enriched with description + category
5. Account deletion with "type DELETE" confirmation
6. Profile metadata: createdAt + lastLoginAt
7. Onboarding hydration from GET /onboarding + DOB field
8. Fake hardcoded streak REMOVED
9. Quest history: assignedAt + completedAt dates shown

## DB schema notes
- `attributeHistoryTable` exists and is queried by GET /progression/attribute-history
- `progressionConfig` in quest_templates is JSON; parse client-side for `xp` and `attributes` array
- Quest status enum: ASSIGNED | IN_PROGRESS | COMPLETED | ABANDONED
